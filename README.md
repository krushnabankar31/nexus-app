# Nexus — Next-Gen Community Platform

Nexus is a modern, real-time community and messaging platform built with Next.js 14, React 18, Tailwind CSS, and Firebase.

## ✨ Features

- **Real-Time Communities**: Public and private spaces, channel-based discussions, and moderation workflows.
- **Direct Messaging & WebRTC**: High-speed chat, voice notes, photo sharing, and peer-to-peer audio/video calling.
- **Privacy & Safety First**: Server-side profile protection, user verification, report/block safety controls, and granular permissions.
- **Responsive Midnight Design**: Custom dark-purple aesthetic with glassmorphism, responsive navigation, and focus mode.
- **Full Accessibility (a11y)**: WCAG AA contrast compliance, keyboard navigation, and screen reader announcements.

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS & Framer Motion
- **State Management**: Zustand & TanStack Query
- **Backend & Auth**: Firebase Authentication & Cloud Firestore
- **Real-time Media**: WebRTC & Simple-Peer

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/krushnabankar31/nexus-app.git
   cd nexus-app
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
